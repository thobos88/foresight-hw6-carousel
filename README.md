# Брендбук → скилл «карусель» → карусель

Домашнее задание недели 6 курса Foresight («База знаний, Docker и обвязка»). Канал — «В работу!» (t.me/khazarzhiyan).

## Что здесь

- `brandbook.md` — короткий брендбук канала: 3 цвета, шрифты, тон, 5 правил оформления, 3 запрета. Сделан в ChatGPT, затем поправлен по результатам первого прогона.
- `.claude/skills/carousel/` — скилл для Claude Code: из темы — карусель 6–8 слайдов 1080×1350 по брендбуку.
  - `SKILL.md` — порядок работы и правила текста (заголовок ≤ 6 слов, ≤ 25 слов на слайд, одна мысль на слайд);
  - `template.html`, `carousel.css` — шаблон слайда;
  - `render.mjs` — рисует PNG через Playwright и проверяет каждый слайд: текст не выходит за край и поля, контраст ≥ 4,5:1, загружены шрифты с кириллицей.
- `carousel/` — первый результат: «Карта обвязки: как ИИ работает в моём бизнесе», 8 слайдов, `preview.png` — все слайды на одном листе.
- `evidence/` — скриншот для проверки и негативный тест: нарочно плохой слайд, скрипт ловит все три ошибки и выходит с кодом 1.

## Как запустить

```bash
node .claude/skills/carousel/render.mjs carousel/slides.html
```

Нужен Node.js и пакет `playwright` с установленным Chromium.
